# BlueoothCommongKit

BluetoothCommonKit provides common services, extensions, and managers to support device integration into a [LoopKit](https://github.com/tidepool-org/LoopKit) based iOS app.

## Included Services

- Authorization Control Service
- Battery Service
- Device Information Service
- Device Time Service
- Imediate Alert Service

## Included Helpers

 - SFLOAT and FLOAT implementations
 - Security Manager
 - E2E Protection (CRC and CRC counter)
 - Segmentation and Assembly
