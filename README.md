# BlueoothCommongKit

BluetoothCommonKit provides common services based on published Bluetooth specifications. Following is a list of included services and helper functions.

## Included Services

- Authorization Control Service
- Battery Service
- Device Information Service
- Device Time Service
- Imediate Alert Service

## Included Helpers

 - SFLOAT and FLOAT implementations
 - Security Manager
 - E2E Protection (CRC and CRC counter)
 - Segmentation and Assembly
